# edge-cv-lab: working rules

Portfolio repo. A virtual edge computer-vision lab that reproduces and fixes video-analytics failures
with no cameras, no edge boxes and no GPU. Read HANDOVER.md for status and the task queue.

## Hard rules
- No employer, client or product names anywhere: code, docs, commits, fixtures, comments. Frame everything
  as a generic industry problem. If you see a term that looks internal, rename it.
- Never write a number into docs that was not produced by a command in this repo. `TBD` stays `TBD`
  until measured. Record the command that produced every figure.
- Footage is never committed. Every clip is logged in `media/SOURCES.md` with URL, author, licence.
  Research-licensed datasets (UA-DETRAC, MOT17, etc.) contribute metrics and citations only, never frames,
  GIFs or screenshots.
- `harness/replay/zones.py` and `harness/replay/trackers/` are shared with the running services. Behaviour
  changes need a test in `harness/tests/` first. `make test` must stay green.
- `make fixtures` must be byte-reproducible (CI diffs it). Any change to `synth.py` regenerates fixtures
  in the same commit.
- Small, scoped commits. One concern per commit. Conventional prefixes: feat, fix, docs, ci, chore.

## Layout
- `harness/` Python package `replay`: schema, zones, trackers, score, compare, viz. Pure Python, no torch.
  `pip install -e "harness[dev]"` for tests, `[viz]` for images, `[video]` for YOLO.
- `services/` sim, edge, ingest containers. `docker-compose.yml` with profiles `sim` and `video`.
- `chaos/` Toxiproxy scenarios. `grafana/` provisioned dashboard. `tools/label.html` ground-truth labeller.
- `docs/` case study, architecture, trackers, datasets. `docs/img/` is generated by `make visuals` and
  `make trackers`; never hand-edit those images. `docs/screenshots/` holds hand-captured images, with the
  capture steps noted where each is used.

## Commands
